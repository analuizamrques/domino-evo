# Dominó EVO - Desenvolvimento

## Quick Commands

### 1. Abrir no Browser
```bash
open index-2.html
```

### 2. Editar com Aider
```bash
aider index-2.html server.js
```

### 3. Servidor Local
```bash
node server_local.js
```

### 4. Push
```bash
git add -A
git commit -m "Update"
git push origin main
```

## Arquivos

- index-2.html = Jogo main
- server.js = Servidor
- server_local.js = Servidor local
- dev.sh = Menu
